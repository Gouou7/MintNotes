## 文档边界

- `README.md` 是简洁的产品入口；行为细节应写入上方对应的任务指南。
- 用户可见行为写入用户指南。编辑器不变量写入编辑器架构指南；系统拓扑、安全、部署、发布和恢复分别保留在各自的权威指南中。
- 应链接到权威指南，不要在多个文件中复制冗长流程。
- 命令、配置名称、限制和兼容性声明必须与实现及提交到仓库的配置保持一致。
