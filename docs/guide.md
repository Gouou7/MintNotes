# 使用指南

[返回项目说明](../README.md)

这里记录 Mint Notes 当前已经提供的功能，以及用户在实际使用中会遇到的行为。尚未实现的设想不写入本指南；功能发生变化时，应在同一次修改中更新相应说明。

## 账户与恢复

首个账户自动成为管理员。之后可开启公开注册，或使用管理员生成的 72 小时一次性激活码。用户名为 3–48 个小写字母、数字、`.`、`_` 或 `-`；主密码至少 10 个字符。

注册时只显示一次恢复密钥。请保存到密码管理器或受保护的离线位置；没有它就无法在忘记密码后恢复保险库。修改主密码只重新包装保险库密钥，恢复密钥不变；重置恢复密钥会立即废止旧密钥。修改用户名需要在线验证主密码和恢复密钥，也可同时生成替代恢复密钥。

## 笔记与编辑器

桌面界面依次为文件树、编辑器和大纲／历史面板；窄屏将侧栏变为抽屉。布局、主题、语言、字号、排序和编辑模式只保存在当前浏览器。

文件树支持文件夹、固定、搜索、四种排序、多选、拖放、复制与批量操作。同级名称不能重复；文件夹不能移入自身或后代。锁定笔记可查看、移动、复制和导出，但不能编辑或移入回收站；副本默认解锁。

编辑器始终以原始 Markdown 为权威内容：

- **实时模式：**光标进入语法范围或紧邻边界时显示相关源码；标题和列表按源码行展开，普通引用按未被普通空行隔开的整块展开，并保留正文排版。非空选区覆盖的单元和两端所在单元全部进入编辑态；鼠标拖选期间暂缓切换，松开后一起展开。
- **源码模式：**直接编辑完整 Markdown，包括 Front Matter 和表格结构标记。
- **阅读模式：**只读渲染。

Setext 标题在实时模式中保留两行布局：标题文字按 H1／H2 显示，下划线标记行按正文高度占位。光标位于标题文字或下划线任一行时，下划线会以较弱颜色显示；离开整个标题后标记隐藏，但原有行位保持不变。

ATX 标题（`# 标题`）进入编辑态时，井号标记与对应级别的标题使用相同字号；这不影响 Setext 下划线标记继续按正文字号显示。

列表（含多级、有序和任务列表）、引用和标题显示行首源码标记时，优先使用已有缩进和左侧留白，尽量保持正文的横向位置；任务标记沿用复选框的占位，列表续行不会重复叠加源码缩进。较长标记超出可用留白时，正文只为超出部分让位。行内格式展开仍保留正文的字号、行高与样式。

普通引用在实时模式中以未被普通空行隔开的完整引用块作为编辑单元。渲染态显示左侧引用竖条并隐藏 `>`；光标进入块内任意一行后，编辑态隐藏竖条，并以较弱颜色显示同一块内所有 `>`。只有 `>` 的空引用行仍属于当前引用块并占一行，连续空引用行按源码行数显示，竖条不会额外延伸到多余的空行。Callout 在渲染态显示对应样式并隐藏 Markdown 标记，编辑态显示完整 Markdown 源码。

支持 GFM、任务列表、脚注、KaTeX、Mermaid、WikiLink／嵌入、Obsidian 风格 Callout、注释和 YAML Front Matter。嵌套 YAML、多行值、锚点与别名只能在源码模式编辑；无效语法保持源码，不会被静默改写。原始 HTML 和可执行嵌入禁用。大纲从 H1–H6 在本地派生，不上传明文。

三种模式共用正文、选区位置和撤销历史。模式切换与图片加载只更新展示，不保存正文；输入法组合输入期间推迟可能打断输入的模式与展示切换。普通左右移动和删除按完整字符处理，表情符号和组合字符不会被拆开；实时模式的左右键也会经过隐藏的格式标记。

使用键盘输入、换行或导航时，编辑区会跟随光标即时滚动，使当前编辑位置保持在笔记的可视区域内。

常用编辑规则：普通文本中每次 Enter 都将光标推进到下一行，连续 Enter 会逐行创建空行；Enter 延续列表或引用，空项再次 Enter 退出；Shift+Enter 写入硬换行或列表续行；Tab／Shift+Tab 以 4 个空格调整列表层级。一次剪切、替换或辅助命令可以通过一次撤销恢复。普通文本粘贴保留收到的原文，不因所在格式自动转义或整理；修改范围外的空格、换行及标记写法保持原样。

能够准确映射的表格始终直接编辑单元格，Callout 内也如此。单元格边界使用方向键、Tab／Shift+Tab 导航，Enter 进入下一行同列；文档边缘没有相邻内容时停留在表格内。Cmd／Ctrl+Enter 在当前行下方增加空行，Cmd／Ctrl+Shift+Backspace 删除当前数据行（表头保留）；工具栏可调整行列数量、列对齐或删除整张表格。调整行数时计入表头，不计 Markdown 分隔行。修改单元格不会自动整理整张表格；结构标记可在源码模式编辑。

点击图片或将光标移到图片源码的前后边界，会在预览上方显示可编辑源码，预览继续保留。代码、公式、Mermaid 和普通 Callout 使用整块源码编辑；空代码块相邻的开闭围栏也会在编辑时同时显示、离开后同时隐藏。点击 Callout 预览从标记行进入，键盘也可通过源码边界进入。含表格的 Callout 保留展开的容器和原生单元格，其他文字行按整块激活。

普通复制逐字取得实际选中范围的源码；只选中标题正文就只复制正文，跨越格式标记的选区则包含标记。剪切复制与删除完全相同的范围。表格跨单元格复制使用两端源码位置间的连续范围，包含中间结构标记；跨单元格剪切先切换源码模式并保留选区，再次剪切才执行删除。阅读视图通过文字来源定位选区；遇到无法准确映射的展示内容时，先显示只读源码供重新选择。编辑模式中的不确定操作同样先回退源码，不根据渲染结果猜测或修复正文。

代码块的专用“复制代码”按钮复制显示的代码正文并带末尾换行，不包含围栏；普通选区复制仍遵循源码范围。

## 保存、同步与冲突

输入立即进入内存，空闲 500 ms 后加密写入 IndexedDB，最迟 5 秒持久化；网络上传在后台批处理。状态栏区分“已同步”“同步中”“离线 · 已保存到本地”和“同步错误 · 已保存到本地”。本地加密或 IndexedDB 失败会显示持续严重警告，此时不要清除站点数据或关闭保险库。

重新联网、解锁、页面恢复可见和周期检查会触发同步。并发编辑不会按设备时间覆盖：服务器版本保留，本地版本成为独立冲突副本；附件也会复制到新 ID。Service Worker 和 SSE 只用于改善及时性，不决定正确性。

## 图片、历史与回收站

可拖放、粘贴或选择 PNG、JPEG、GIF、WebP、AVIF 图片；SVG 被拒绝，单图上限 25 MiB。附件先在 IndexedDB 中加密持久化，再插入 Markdown 引用并上传约 1 MiB 的分块。每个附件只属于一篇笔记；复制笔记、冲突副本或恢复为副本会生成新 ID 与密钥。

历史默认自动启用，活动编辑每 10 分钟检查，默认保留 90 天；另可手动保存、命名和保护版本。恢复当前版本前会创建安全检查点，也可恢复为同级副本。受保护版本仍占配额，但不会被普通删除、历史清理或相关笔记／附件的永久清除移除。

回收站默认保留 30 天，可改为 7、90、180、365 天或永久。永久删除和清空需要在线确认，且无法撤销；包含受保护历史的批次会被拒绝。笔记锁只防误操作，不是密码或服务器权限。

## 导入与导出

设置中的数据迁移支持 Markdown、文本和 ZIP。ZIP 保留目录与空文件夹；相对图片仅在内容有效且每张不超过 25 MiB 时导入。压缩包最多 4,000 个文件，并拒绝重复路径和路径穿越。

无附件笔记导出为 `.md`，含附件或文件夹导出为 ZIP；附件写入 `_attachments/`，链接改为相对路径。导入、导出和附件处理都在浏览器完成。导出是明文，必须保存到可信或另行加密的位置；附件不完整时操作会停止。

## 设备安全与离线

“记住此设备”允许持久会话和离线冷启动。可设置至少 4 个字符的本地 PIN，并选择 1–60 分钟自动锁定；短 PIN 可能被离线猜测。锁定会清除内存密钥、明文和 Blob URL，但保留密文缓存与发件箱。

离线恢复期间可以编辑本地数据，但同步、远程附件、账户和管理操作保持禁用，直到服务器重新验证同一端点。远程撤销要等设备联网后生效。

登出与锁定不同：确认登出会删除当前账户在该浏览器中的全部数据，包括未同步更改、PIN、偏好和密文缓存；服务器上已同步内容不受影响。清除站点数据同样会失去离线访问与可能尚未同步的唯一副本。

PWA 可通过 HTTPS 安装。出现更新提示时，先确认状态栏显示最新编辑已保存到本地，再允许激活新版本。
