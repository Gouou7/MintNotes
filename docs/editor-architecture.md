# 编辑器架构

[返回项目说明](../README.md) · [系统设计](system-design.md)

Mint 编辑器以原版 Typora-web 的功能组织、解析、序列化和交互为基础。本文记录已采纳的设计约束；变更这些约束须先获得用户许可。版本变化见[变更日志](../CHANGELOG.md)。

## 上游与生成流程

基准为 [Typora-web v0.3.1，提交 317fdb0](https://github.com/Yuyz0112/typora-web/tree/317fdb0f89a38cfc98a0bba753deec979c6722e6)。

| 位置 | 职责 |
| --- | --- |
| `src/editor/typora-web/` | 不修改的上游源码、样式、测试、specs、README、包信息与完整 MIT 许可 |
| `src/editor/typora-web/upstream.json` | 来源、版本、完整提交号与逐文件 SHA-256 清单 |
| `src/editor/patches/` | 按功能归档的补丁、新增模块及 `series.json` 应用顺序 |
| `.generated/typora-web/` | 忽略的可运行源码，由准备脚本重建 |
| `src/editor/engine.ts` | 产品访问生成引擎的受限控制器入口 |
| `src/editor/product/` | React 集成、属性面板、安全渲染与产品辅助模块及相邻测试 |
| `src/editor/tests/`、`src/editor/types/` | 引擎回归测试与上游类型声明 |

`scripts/prepare-typora-web.mjs` 校验完整基准、复制文件、按声明顺序应用补丁，并校验生成文件。补丁只接受指定偏移与完全一致的上下文；上下文不匹配、基准被改动或路径越界时立即失败，不猜测合并。开发、类型检查、测试和客户端构建调用同一准备流程；构建不联网，不需要系统 Git 或 patch 命令，也不导入上游包管理器锁文件。

每个补丁功能使用不带序号的语义目录，包含 `upstream.patch` 和该功能新增模块；应用顺序由 `series.json` 的数组顺序决定。原始上游和补丁素材不直接参与 Mint 常规类型检查或测试收集；类型检查沿产品入口检查生成引擎，上游测试使用独立配置。

新增功能优先使用上游 `FeatureSpec`、MarkdownIt 插件、解析 token、序列化处理器和 ProseMirror 插件。补丁承担上游缺口及必要的产品接入点，不复制旧核心的源码映射、输入重建和独立阅读转换。补丁职责、依赖、测试与升级步骤见[补丁来源与维护说明](../src/editor/patches/README.md)。

## 正文与编辑提交

完整 Markdown（含 Front Matter）是唯一持久化、历史、同步和导出的正文。实时模式采用上游 ProseMirror 文档模型，实际编辑后由上游序列化器生成 Markdown；源码模式使用原生 textarea 编辑完整正文。

允许编辑后的等价格式规范化，例如强调标记、Setext 标题、列表缩进、表格对齐、空行和换行写法发生变化。不得丢失正文、链接目标、未使用或重复标签的引用定义、附件引用及已有扩展内容。代码和 YAML 内容不得被行内语法归一化。未完成或未知语法保留为可编辑内容。

引用符号 `>` 不自动转义。在段落开头输入 `>` 加空格建立引用块，浏览器合并输入事件时保留同时输入的正文；引用嵌套、延续、退出及输入规则撤销采用上游行为。手写 `\>` 表示字面字符，编辑后保留该转义。代码中的引用符号与反斜杠原样保留。

首次载入、光标移动、模式切换、主题调整、语法显隐、附件 URL 更新和异步渲染不触发正文回调，不自动保存。实际编辑提交与输入法结束提交可以触发回调；回调携带文档身份，工作区按该身份查找并更新对象，不把旧文档的延迟结果写入当前笔记。

## 模式、选区与撤销

- **实时模式**：基础键盘、输入规则、表格、剪贴板和撤销遵循上游。显示和编辑由同一引擎管理。
- **源码模式**：完整 Markdown 在 textarea 中编辑，原生文本选区和浏览器撤销适用；返回实时模式重新解析。
- **阅读模式**：使用同一解析器与功能注册的只读引擎，拒绝改变正文的事务。笔记锁和历史预览同样只读。

实时与阅读之间保持同一控制器；源码模式与实时模式之间不承诺统一撤销历史。切换笔记或外部替换正文会建立新的编辑状态。普通复制、剪切和粘贴遵循所在输入表面的上游或浏览器行为，不承诺复刻旧版逐字源码剪贴板。

控制器向产品提供载入、模式切换、变更回调、焦点、近似源码位置、标题跳转、展示刷新、插入书签、组合输入状态和销毁接口。ProseMirror 类型及视图访问限于引擎、补丁和引擎测试；业务组件不直接派发 ProseMirror 事务。跨模式选区位置仅用于导航恢复，不作为精确源码事务依据。大纲使用同一上游 MarkdownIt 实例提取顶层标题，Setext 和未完成列表的解释以上游为准。

输入法沿用 ProseMirror／浏览器原生机制。组合期间不重建输入区域，推迟模式和文档切换；结束后合并提交，避免重复回调。不得重新引入旧版 DOM 输入重建机制。

## Mint 功能补丁

| 功能 | 保留行为 |
| --- | --- |
| 公式 | `$…$`、`$$…$$` 与独立块公式；KaTeX 本地渲染，禁用信任模式 |
| Mermaid | 声明为 Mermaid 的代码块生成安全预览；失败保留源码编辑入口 |
| WikiLink | `[[笔记#标题\|别名]]`、路径及标题导航；嵌入语法保留并提供导航入口 |
| Callout | 类型、别名、标题、`+`／`-` 折叠、嵌套及颜色／图标属性；正文编辑保留标题，仅编辑标记行时显示源码；点击图标使用原生选单切换类型，保留自定义标题并采用新类型默认外观；标题直接编辑，回车／失焦提交；空正文退格返回标记，折叠只改变展示 |
| 脚注 | 引用定义、重复引用、行内脚注、编号及跳转；定义正文使用同一只读解析器 |
| 注释 | `%%…%%` 隐藏展示，保留源码；不解释代码中的字面语法 |
| Front Matter | 属性面板保留文本、数值、布尔、日期和列表类型；复杂或无效 YAML 在源码中编辑 |
| 代码 | 点击头部语言标签直接编辑完整围栏信息，回车／失焦提交；复制代码正文并带末尾换行；本地 highlight.js 按声明语言提供装饰，未知或失败时显示普通代码 |

高亮首批支持 JS／TS、JSON、HTML／XML、CSS、Python、Shell、YAML、Markdown 和 SQL。使用 [highlight.js 的字符串 API](https://highlightjs.readthedocs.io/en/latest/api.html#highlight)，验证返回内容的文字与代码完全相同后，只提取受限的 span 类名和字符范围。不调用会重写可编辑 DOM 的高亮 API。

原始 HTML、可执行嵌入、运行时 CDN 脚本和远程字体禁用。Mermaid 继续使用严格配置、清理后的 SVG 与可撤销 Blob URL；渲染和控件卸载须清理异步结果、计时器、监听器及资源。

## 附件、图片与工作区

工作区通过 `useNoteEditorIntegration` 管理正文提交和附件保存身份，通过 `useDocumentNavigation` 管理视口与大纲导航。保存仍进入原有本地优先队列；编辑器不访问存储、加密 Worker 或同步 API。

附件先加密持久化，再插入 `webmd-attachment:` 引用。异步操作绑定文档身份和输入表面的位置书签；书签随同表面编辑移动。文档切换、锁定、销毁、模式切换或定位失效时取消插入并提示重试，不猜测插入到另一篇笔记。

附件 Blob URL 仅由产品解析器提供，正文不得写入 Blob URL。外部图片只显示 HTTPS，使用 `no-referrer`；失败图片在重新联网或回到可见前台时可重试。重试只更新实际预览，不额外探测代码或 YAML 内的图片地址。附件 URL 生命周期和锁定清理由现有工作区控制器负责。

## 样式边界

上游 `widgets.css` 和 `theme-typora.css` 原样使用，实时和阅读模式共用正文样式。`src/editor/product/typora-overrides.css` 是唯一 Mint 编辑器覆盖入口，仅管理主题颜色、字号偏好、代码换行、容器滚动、移动布局及新增功能样式。后续视觉调整集中于该文件，不修改上游主题或恢复旧版排版覆盖。

控件图标通过 AppIcon 和显式 Lucide 导入渲染；新增产品文案提供英文、简体中文与繁体中文，纯图标按钮具有可翻译的可访问名称。

## 验收

原始上游测试与补丁后的测试分别运行，完整保留原始 tests 和 specs。只有实际改变的行为可修改生成测试预期，并以独立补丁解释原因；不得静默跳过测试。

Mint 回归同时验证序列化内容和真实浏览器交互，覆盖嵌套、未完成输入、代码中的字面语法、只读边界、加载与模式切换不保存、输入法提交、延迟附件、资源销毁、属性、表格、图片、高亮与复制。准备脚本测试须覆盖干净目录、基准篡改、错误上下文和路径越界。

浏览器验收使用单工作进程，覆盖 Chromium、Firefox、WebKit，以及桌面／平板／手机尺寸、浅深色、字号、代码换行和工作区滚动容器。每轮结束关闭本轮浏览器与临时服务。模拟事件和移动视口不能替代真实 iPhone／iPad 输入法、软键盘、安全区域、PWA 和触摸剪贴板验证；交付时明确实际通过的检查与剩余人工验证。
