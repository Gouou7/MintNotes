# 编辑器架构

[返回项目说明](../README.md) · [系统设计](system-design.md)

Mint 编辑器以原版 Typora-web 的功能组织、解析、序列化和交互为基础。本文记录已采纳的设计约束；变更这些约束须先获得用户许可。版本变化见[变更日志](../CHANGELOG.md)。

## 上游与生成流程

基准为 [Typora-web v0.3.1，提交 317fdb0](https://github.com/Yuyz0112/typora-web/tree/317fdb0f89a38cfc98a0bba753deec979c6722e6)。

| 位置 | 职责 |
| --- | --- |
| `src/editor/typora-web/` | 不修改的上游源码、样式、测试、specs、README、包信息与完整 MIT 许可 |
| `src/editor/typora-web/upstream.json` | 来源、版本、完整提交号与逐文件 SHA-256 清单 |
| `src/editor/patches/` | 按功能归档的补丁、新增模块及 `series.json` 应用顺序 |
| `.generated/typora-web/` | 忽略的可运行源码，由准备脚本重建 |
| `src/editor/engine.ts` | 产品访问生成引擎的受限控制器入口 |
| `src/editor/product/` | React 集成、属性面板、安全渲染与产品辅助模块及相邻测试 |
| `src/editor/tests/`、`src/editor/types/` | 引擎回归测试与上游类型声明 |

`scripts/prepare-typora-web.mjs` 校验完整基准与补丁清单，按声明顺序在内存中应用补丁及新增模块，再计算生成指纹。正常准备时核对现有生成文件的摘要，文件缺失、被修改或指纹变化时重建生成树；`--check` 只校验基准与补丁能否严格应用，不检查或修复现有生成树。补丁只接受指定偏移与完全一致的上下文；上下文不匹配、基准被改动或路径越界时立即失败，不猜测合并。

编辑器准备过程不联网，不需要系统 Git 或 patch 命令，也不导入上游包管理器锁文件。客户端开发、类型检查、Mint 测试、上游测试与客户端构建会自动准备编辑器；单独运行 Vitest 时须先确保生成树已更新。

每个补丁功能使用不带序号的语义目录，可包含多个补丁文件与该功能新增模块。`series.json` 逐项指定补丁路径和新增模块映射，数组顺序决定应用顺序；例如 `block-controls/` 同时维护实现补丁与测试预期补丁。原始上游和补丁素材不直接参与 Mint 常规类型检查或测试收集；类型检查沿产品入口检查生成引擎，上游测试使用独立配置。

新增功能优先使用上游 `FeatureSpec`、MarkdownIt 插件、解析 token、序列化处理器和 ProseMirror 插件。补丁承担上游缺口及必要的产品接入点，不复制旧核心的源码映射、输入重建和独立只读渲染链。补丁职责、依赖、测试与升级步骤见[补丁来源与维护说明](../src/editor/patches/README.md)。

## 正文与编辑提交

完整 Markdown（含 Front Matter）是唯一持久化、历史、同步和导出的正文。渲染界面中的实时编辑采用上游 ProseMirror 文档模型，实际编辑后由上游序列化器生成 Markdown；源码界面使用原生 textarea 显示完整正文，允许编辑时直接修改文本。

允许编辑后的等价格式规范化，例如强调标记、Setext 标题、列表缩进、表格对齐、空行和换行写法发生变化。不得丢失正文、链接目标、未使用或重复标签的引用定义、附件引用及已有扩展内容。代码和 YAML 内容不得被行内语法归一化。未完成或未知语法保留为可编辑内容。

引用符号 `>` 不自动转义。在段落开头输入 `>` 加空格建立引用块，浏览器合并输入事件时保留同时输入的正文；引用嵌套、延续、退出及输入规则撤销采用上游行为。手写 `\>` 表示字面字符，编辑后保留该转义。代码中的引用符号与反斜杠原样保留。

首次载入、光标移动、显示方式与只读切换、主题调整、局部语法显隐、附件 URL 更新和异步渲染本身不触发正文回调，不自动保存。实际编辑提交与输入法结束提交可以触发回调；回调携带文档身份，工作区按该身份查找并更新对象，不把旧文档的延迟结果写入当前笔记。

## 显示方式与只读

编辑器通过“显示源码”选择渲染界面或源码界面，通过“只读”控制是否允许修改正文。两个开关独立，可组合为以下状态：

| 显示源码 | 只读 | 正文行为 |
| --- | --- | --- |
| 关闭 | 关闭 | 在渲染界面实时编辑 |
| 关闭 | 开启 | 在渲染界面只读查看 |
| 开启 | 关闭 | 编辑完整 Markdown 源码 |
| 开启 | 开启 | 查看、选择和复制完整 Markdown 源码 |

- **渲染界面**：显示与编辑由同一引擎管理，可编辑与只读状态共用解析器、功能注册和正文样式。可编辑时，基础键盘、输入规则、表格、剪贴板和撤销遵循上游；只读时拒绝改变正文的事务。
- **源码界面**：完整 Markdown 在 textarea 中显示，允许编辑时使用原生文本选区和浏览器撤销；返回渲染界面重新解析。只读时禁止修改，但保留选择和复制。

渲染界面中图片、公式等语法的局部源码展开只改变展示，不切换整个编辑界面，也不改变只读开关。正文、Front Matter 属性与块控件等修改入口均须遵守有效的只读状态。

两个开关沿用当前设备的统一偏好，保存与生效范围见[系统设计](system-design.md#笔记组织与本地偏好)。

笔记保护强制只读，仍允许切换、选择和复制源码；保护与只读按钮显示启用状态，只读按钮置灰不可切换。强制只读不改写用户保存的只读偏好，解除保护后按原偏好恢复。

历史预览固定使用只读渲染界面，禁用两个开关，不改变设备偏好。

## 选区、撤销与输入法

渲染界面切换只读时保持同一控制器；源码与渲染界面之间不承诺统一撤销历史。切换笔记或外部替换正文会建立新的编辑状态。普通复制、剪切和粘贴遵循所在输入表面的上游或浏览器行为，不承诺复刻旧版逐字源码剪贴板。

跨界面的选区位置仅用于导航恢复，不作为精确源码事务依据。输入法沿用 ProseMirror／浏览器原生机制；组合期间不重建输入区域，推迟显示方式、只读和文档切换，结束后合并提交，避免重复回调。不得重新引入旧版 DOM 输入重建机制。

## Mint 功能补丁

下表中的编辑交互受只读约束；可编辑与只读的渲染展示复用同一解析及功能注册机制。

| 功能 | 保留行为 |
| --- | --- |
| 公式 | `$…$` 行内公式、段落内 `$$…$$` 兼容展示，以及单行／多行 `$$` 独立公式块；美元分隔符共用语法规则，代码和转义不解释为公式，未闭合内容保留源码；行内点击或选区进入后显示源码，块预览点击后进入正文，独立行输入 `$$` 后回车创建公式块，块内回车换行，Ctrl／Command+Enter 或边界上下键退出；渲染界面使用本地 KaTeX，禁用信任模式，展示变化不提交正文 |
| Mermaid | 声明为 Mermaid 的代码块生成安全预览；失败保留源码编辑入口 |
| WikiLink | `[[笔记#标题\|别名]]`、路径及标题导航；嵌入语法保留并提供导航入口 |
| Callout | 类型、别名、标题、`+`／`-` 折叠、嵌套及颜色／图标属性；输入标记行后回车创建并进入正文，空正文回车继续在块内换行；上下导航依次经过块上方、名称编辑框、正文和块下方，名称确认后进入正文开头；空块保留一行正文空位，标记源码在源码界面编辑；点击图标使用原生选单切换类型，保留自定义标题并采用新类型默认外观；名称直接编辑，回车／失焦提交，折叠只改变展示 |
| 脚注 | 引用定义、重复引用、行内脚注、编号及跳转；定义正文通过同一引擎只读渲染 |
| 注释 | `%%…%%` 隐藏展示，保留源码；不解释代码中的字面语法 |
| Front Matter | 属性面板保留文本、数值、布尔、日期和列表类型；复杂或无效 YAML 在源码中编辑 |
| 普通代码块 | 点击头部语言标签直接编辑完整围栏信息，回车／失焦提交；复制代码正文并带末尾换行；本地 highlight.js 按声明语言提供装饰，未知或失败时显示普通代码；Mermaid 代码块使用单独的预览与正文编辑界面 |
| 图片 | 可编辑时普通点击预览，在图片上方展开 Markdown 源码并将光标置于该图片源码末尾；选区涉及图片语法时保持展开，离开后收起；只读时保留预览，不进入源码编辑 |

高亮首批支持 JS／TS、JSON、HTML／XML、CSS、Python、Shell、YAML、Markdown 和 SQL。使用 [highlight.js 的字符串 API](https://highlightjs.readthedocs.io/en/latest/api.html#highlight)，验证返回内容的文字与代码完全相同后，只提取受限的 span 类名和字符范围。不调用会重写可编辑 DOM 的高亮 API。

原始 HTML、可执行嵌入、运行时 CDN 脚本和远程字体禁用。Mermaid 继续使用严格配置、清理后的 SVG 与可撤销 Blob URL；渲染和控件卸载须清理异步结果、计时器、监听器及资源。

## 工作区、导航与附件

工作区通过 `useNoteEditorIntegration` 管理正文提交和附件保存身份，通过 `useDocumentNavigation` 管理视口与大纲导航。保存仍进入原有本地优先队列；编辑器不访问存储、加密 Worker 或同步 API。

控制器向产品提供载入、显示方式与只读切换、变更回调、焦点、近似源码位置、标题跳转、展示刷新、插入书签、组合输入状态和销毁接口。ProseMirror 类型及视图访问限于引擎、补丁和引擎测试；业务组件不直接派发 ProseMirror 事务。大纲使用同一上游 MarkdownIt 实例提取顶层标题，Setext 和未完成列表的解释以上游为准。

附件先加密持久化，再插入 `webmd-attachment:` 引用。异步操作绑定文档身份和输入表面的位置书签；书签随同表面编辑移动。文档切换、锁定、销毁、显示方式切换、进入只读或定位失效时取消插入并提示重试，不猜测插入到另一篇笔记。

附件 Blob URL 仅由产品解析器提供，正文不得写入 Blob URL。外部图片只显示 HTTPS，使用 `no-referrer`；失败图片在重新联网或回到可见前台时可重试。重试只更新实际预览，不额外探测代码或 YAML 内的图片地址。附件 URL 生命周期和锁定清理由现有工作区控制器负责。

## 样式边界

上游 `widgets.css` 和 `theme-typora.css` 文件保持原样，最终展示由 Mint 覆盖层补充。`src/editor/product/typora-overrides.css` 是唯一 Mint 编辑器覆盖入口，管理主题颜色、字号与代码换行偏好、容器滚动与移动布局，以及代码块、图片、公式、Callout、脚注和属性面板的展示与控件样式。基础排版仍以上游主题为准；后续视觉调整集中于该文件，不修改上游主题或恢复旧版排版覆盖。

控件图标通过 AppIcon 和显式 Lucide 导入渲染；新增产品文案提供英文、简体中文与繁体中文，纯图标按钮具有可翻译的可访问名称。

## 验收

原始上游测试与补丁后的测试分别运行，完整保留原始 tests 和 specs。只有实际改变的行为可修改生成测试预期，并以独立补丁解释原因；不得静默跳过测试。

Mint 回归同时验证序列化内容和真实浏览器交互，覆盖两个开关的四种组合、笔记保护与历史预览的只读边界、加载与开关切换不保存，以及嵌套、未完成输入、代码中的字面语法、输入法提交、延迟附件、资源销毁、属性、表格、图片、高亮与复制。准备脚本测试须覆盖干净目录、基准篡改、错误上下文和路径越界。

浏览器验收使用单工作进程，覆盖 Chromium、Firefox、WebKit，以及桌面／平板／手机尺寸、浅深色、字号、代码换行和工作区滚动容器。每轮结束关闭本轮浏览器与临时服务。模拟事件和移动视口不能替代真实 iPhone／iPad 输入法、软键盘、安全区域、PWA 和触摸剪贴板验证；交付时明确实际通过的检查与剩余人工验证。
